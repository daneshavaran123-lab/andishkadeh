# نصب و پیکربندی کیوسک ویندوز

راهنمای نصب برنامه کیوسک روی دستگاه ۴۳ اینچ عمودی (ویندوز ۱۰/۱۱ x64) با نمایشگر لمسی، کارتخوان بانکی، اسکنر QR و چاپگر حرارتی ۸۰ میلی‌متری.

## ۱. ساخت نصب‌کننده

روی یک سیستم ویندوز با Node.js 22 و pnpm:

```powershell
pnpm install --frozen-lockfile
pnpm --filter @andishkadeh/shared build
pnpm --filter @andishkadeh/kiosk dist:win
```

خروجی `apps\kiosk\release\AndishkadehKiosk-Setup-<نسخه>.exe` است. این نصب‌کننده NSIS برای همه کاربران (per-machine) است.

- **بدون سیستم ویندوز**: هر push در GitHub Actions (گردش‌کار `Apps`، کار «Windows installer») همین نصب‌کننده را روی ویندوز می‌سازد و با نام `windows-installer` قابل دریافت است.
- **ساخت روی لینوکس** هم ممکن است. برای NSIS به `wine` (۳۲ و ۶۴ بیتی) نیاز است. بدون ویرایش فایل exe، آیکون روی فایل برنامه قرار نمی‌گیرد:

  ```bash
  pnpm --filter @andishkadeh/kiosk build
  cd apps/kiosk && npx electron-builder --win --x64 --publish never -c.win.signAndEditExecutable=false
  ```

- ماژول بومی `better-sqlite3` هنگام ساخت برای Electron (ویندوز) بازسازی می‌شود (`npmRebuild: true`). این کار روی همان `node_modules` انجام می‌شود. برای اجرای دوباره تست‌ها یا bridge روی همان سیستم، نسخه Node را برگردانید: `cd apps/kiosk/node_modules/better-sqlite3 && npx prebuild-install --force`.
- آیکون برنامه در `apps/kiosk/build-resources/icon.ico` است و با `python3 tools/icons/generate.py` دوباره ساخته می‌شود.
- برای امضای دیجیتال، متغیرهای `CSC_LINK` و `CSC_KEY_PASSWORD` electron-builder را تنظیم کنید.
- نسخه وب و اندروید همین برنامه: [کیوسک روی ویندوز، وب و اندروید](kiosk-platforms.md).

## ۲. آماده‌سازی ویندوز

1. **حساب کاربری محلی** بدون رمز یا با ورود خودکار بسازید، مثلاً `kiosk`. حساب مدیر جدا بماند.
2. **ورود خودکار**: با `netplwiz` یا Sysinternals Autologon برای حساب `kiosk`.
3. **برق و نمایشگر**: Power plan روی High performance باشد. خاموش شدن نمایشگر، Sleep و Hibernate را روی Never بگذارید. برنامه هم هنگام اجرا از خواب جلوگیری می‌کند.
4. **جهت نمایشگر**: Display settings → Orientation: Portrait با وضوح 1080×1920. رابط کیوسک برای همین بوم طراحی شده و به اندازه صفحه مقیاس می‌گیرد.
5. **لمس**:
   - Edge swipe را غیرفعال کنید: Group Policy → Computer Configuration → Administrative Templates → Windows Components → Edge UI → *Allow edge swipe* = Disabled.
   - صفحه‌کلید لمسی خودکار را خاموش کنید. کیوسک صفحه‌کلید عددی خودش را دارد.
6. **به‌روزرسانی ویندوز**: ساعت فعال (Active hours) را روی ساعات کاری بگذارید و راه‌اندازی مجدد خودکار را به بیرون از ساعت کاری منتقل کنید.
7. **ساعت سیستم**: همگام‌سازی خودکار زمان روشن باشد. منطقه زمانی Tehran باشد؛ نمایش تاریخ‌ها همیشه بر اساس `Asia/Tehran` است.

## ۳. نصب برنامه

1. **دریافت نصب‌کننده:** روی همین کامپیوتر به صفحه مدیریت کیوسک‌ها بروید (`https://<سرور>/kiosk`) و وارد شوید. کارت «برنامه کیوسک ویندوز» نصب‌کننده هم‌نسخه با سرور را دانلود می‌کند. تا وقتی نصب‌کننده آن نسخه منتشر نشده باشد، همان‌جا نوشته می‌شود «هنوز منتشر نشده». همان فایل در صفحه Releases مخزن هم هست.
2. نصب‌کننده را با حساب مدیر اجرا کنید. پس از نصب، برنامه یک بار اجرا می‌شود.
3. **راه‌اندازی اول:** چون هنوز پیکربندی ندارد، صفحه «راه‌اندازی کیوسک» باز می‌شود. ر.ک. بخش ۴.
4. برنامه در اجرای اول خودش را در Startup حساب جاری ثبت می‌کند. برای حساب `kiosk` یک بار با همان حساب اجرا کنید.
5. پوشه داده برنامه (پیکربندی، پایگاه محلی، کش تصاویر و رسیدها):

   ```
   %APPDATA%\AndishkadehKiosk\
     kiosk.config.json     ← پیکربندی (صفحه راه‌اندازی می‌سازد)
     kiosk.sqlite          ← سفارش‌ها، ژورنال پرداخت، صف همگام‌سازی، کش اشتراک‌ها
     media\                ← کش تصاویر (بررسی‌شده با sha256)
     receipts\             ← فقط در حالت چاپگر شبیه‌سازی‌شده
   ```

   برای مسیر دیگر، متغیر محیطی سیستمی `KIOSK_DATA_DIR` را تنظیم کنید.

## ۴. پیکربندی

### صفحه راه‌اندازی (اجرای اول)

1. در `https://<سرور>/kiosk` با حساب مدیر اصلی وارد شوید و «ثبت کیوسک جدید» را بزنید. فقط یک نام بدهید (شناسه، مثلاً `KIOSK-03`، خودکار انتخاب می‌شود). پنجره «اتصال کیوسک» یک **کد فعال‌سازی ۸ رقمی**، لینک و QR آن را نشان می‌دهد. برای کیوسک موجود (مثلاً پس از تعویض دستگاه)، روی کارت همان کیوسک «کد فعال‌سازی» را بزنید.
   - کد ۳۰ دقیقه معتبر است و فقط یک بار به کار می‌رود.
   - هنگام استفاده، کلید دستگاه روی سرور عوض می‌شود. پس اگر کیوسک دیگری با همان شناسه کار می‌کرد، قطع می‌شود.
2. برنامه را اجرا کنید. صفحه «راه‌اندازی کیوسک» باز می‌شود و آدرس سرور در آن از پیش پر است (نسخه‌های ساخته‌شده در CI). فقط کد را وارد کنید:
   - با صفحه‌کلید عددی روی خود صفحه (صفحه لمسی کیوسک صفحه‌کلید ندارد)
   - یا QR پنجره کد را با اسکنر کیوسک بخوانید. لینک با هر زبان صفحه‌کلید ویندوز، فارسی یا انگلیسی، درست خوانده می‌شود.
3. چاپگر رسید: اگر فقط یک چاپگر واقعی نصب باشد، خودش انتخاب شده است. چاپگرهای مجازی مثل «Microsoft Print to PDF» و XPS حساب نمی‌شوند. پیش از راه‌اندازی، درایور چاپگر را نصب کنید.
4. کارتخوان را انتخاب کنید و «اتصال و شروع» را بزنید: برنامه شناسه و کلید را با کد از سرور می‌گیرد، اتصال را بررسی می‌کند، `kiosk.config.json` را می‌سازد و دوباره اجرا می‌شود. کد نادرست، منقضی یا استفاده‌شده پیام روشن می‌دهد و چیزی ذخیره نمی‌شود.

**روش دستی:** پیوند «اتصال با شناسه و کلید دستگاه» در همان صفحه، آدرس سرور، شناسه و کلید را می‌خواهد. کلید را پنجره ثبت کیوسک (بخش «روش دستی») یا دکمه «کلید جدید» نشان می‌دهد.

صفحه راه‌اندازی فقط وقتی باز می‌شود که `kiosk.config.json` وجود ندارد. برای تغییرات بعدی، فایل را ویرایش کنید یا پاکش کنید تا صفحه دوباره باز شود. داده‌های محلی (`kiosk.sqlite`) با این کار پاک نمی‌شوند.

### فایل `kiosk.config.json`

نمونه کامل در `apps/kiosk/kiosk.config.example.json` است:

```json
{
  "serverUrl": "https://kiosk-api.example.ir",
  "deviceId": "KIOSK-01",
  "deviceKey": "کلید دستگاه از پنل مدیریت",
  "adapters": { "payment": "mock", "printer": "windows", "printerName": "POS-80C", "scanner": "keyboard" },
  "intervals": { "heartbeatSec": 30, "pullSec": 60, "pushSec": 10, "recoverySec": 60 },
  "requestTimeoutMs": 8000,
  "kioskMode": true,
  "devControls": false
}
```

| کلید | توضیح |
| --- | --- |
| `serverUrl` | آدرس سرور مرکزی (HTTPS) |
| `deviceId`، `deviceKey` | از صفحه «کیوسک و تجهیزات» پنل. کلید فقط در main process خوانده می‌شود و به رابط نمی‌رسد |
| `adapters.payment` | `mock` = کارتخوان شبیه‌سازی‌شده (نوار «حالت آزمایشی» نمایش داده می‌شود). `none` = بدون SDK؛ فروش متوقف است و وضعیت کارتخوان «نامشخص» گزارش می‌شود. `helper` = کارتخوان واقعی از طریق برنامه کمکی SDK بانک ([کارتخوان](payment-helper.md)) |
| `adapters.paymentHelperPath`، `adapters.paymentHelperArgs` | فقط برای `helper`: مسیر برنامه کمکی و آرگومان‌های آن (مثلاً IP پایانه) |
| `adapters.printer` | `windows` = چاپ بی‌صدا با درایور نصب‌شده. `mock` = ذخیره رسید در پوشه `receipts` |
| `adapters.printerName` | نام دقیق چاپگر در Devices and Printers |
| `adapters.scanner` | `keyboard` = اسکنر USB HID در حالت keyboard-wedge. `mock` = فقط برای آزمون |
| `intervals` | فاصله ضربان (heartbeat)، دریافت کاتالوگ، ارسال رویدادها و بازیابی پرداخت‌ها (ثانیه) |
| `kioskMode` | تمام‌صفحه بدون قاب، منو و ابزار توسعه؛ در تولید `true` |
| `devControls` | کنترل‌های شبیه‌سازی؛ در تولید باید `false` باشد |
| `adminPanelUrl` | پنلی که چرخ‌دنده باز می‌کند؛ پیش‌فرض `<serverUrl>/admin` |
| `adminIdleMinutes` | خروج خودکار مدیر از پنل روی کیوسک پس از این مدت بی‌فعالیتی (پیش‌فرض ۵ دقیقه) |

همین مقادیر با متغیرهای محیطی هم قابل تنظیم‌اند و اولویت بالاتری دارند:
`KIOSK_SERVER_URL`، `KIOSK_DEVICE_ID`، `KIOSK_DEVICE_KEY`، `KIOSK_PAYMENT_ADAPTER`، `KIOSK_PRINTER_ADAPTER`، `KIOSK_PRINTER_NAME`، `KIOSK_SCANNER_ADAPTER`، `KIOSK_KIOSK_MODE`، `KIOSK_DEV_CONTROLS`.

پس از ذخیره فایل، برنامه را دوباره اجرا کنید. در پنل، دستگاه باید «آنلاین» شود و وضعیت تجهیزات آن نمایش داده شود.

### ورود مدیر از روی کیوسک

چرخ‌دنده کوچک گوشه بالای صفحه اصلی، پنجره «ورود مدیر» را با صفحه‌کلید لمسی باز می‌کند. با نام کاربری و رمز پنل وارد شوید:

- **همان پنل مدیریت** در پنجره‌ای روی کیوسک باز می‌شود (با `kioskMode` تمام‌صفحه). مدیر اصلی به داشبورد و اپراتور به «سفارش‌ها» می‌رود و نشان «روی کیوسک» در بالای پنل دیده می‌شود.
- **خروج:** «خروج و بازگشت به کیوسک». پس از ۵ دقیقه بی‌فعالیتی (`adminIdleMinutes`) یا ۳۰ دقیقه از ورود (`KIOSK_ADMIN_SESSION_MINUTES` سرور) خروج خودکار است. پنجره بسته می‌شود، کیوسک به صفحه اصلی برمی‌گردد و تغییرات پنل همان لحظه همگام می‌شوند.
- **امنیت:**
  - ورود فقط با اتصال به سرور ممکن است.
  - رمز و توکن روی کیوسک ذخیره نمی‌شوند. نشست پنل فقط در حافظه همان پنجره است و با بستن آن پاک می‌شود.
  - فقط صفحه‌های پنل باز می‌شوند.
  - دانلود فایل (خروجی گزارش) و پنجره چاپ پنل در این پنجره کار نمی‌کنند؛ برای آن‌ها از پنل روی کامپیوتر دیگر استفاده کنید.
- **پیش‌نیاز:** پنل روی سرور در `/admin` ارائه شود. اگر پنل باز نشود، پنجره خودش بسته می‌شود و پیام «پنل مدیریت باز نشد» روی کیوسک نمایش داده می‌شود.

## ۵. تجهیزات

### چاپگر حرارتی

- درایور ویندوز سازنده را نصب کنید. عرض کاغذ ۸۰ میلی‌متر و حاشیه صفر باشد. رسید برای عرض چاپی ۷۲ میلی‌متر چیده شده است.
- در Printing Preferences، برش خودکار کاغذ (auto-cut) را فعال کنید.
- درایورهای ویندوز معمولاً «تمام شدن کاغذ» را پیش از چاپ گزارش نمی‌کنند. برنامه نتیجه چاپ را از درایور می‌گیرد و در صورت خطا پیام روشن نشان می‌دهد. سفارش پرداخت‌شده هرگز به خاطر چاپ لغو نمی‌شود. چاپ مجدد از کیوسک یا از پنل («سفارش‌ها» ← «چاپ مجدد») ممکن است.
- اگر مدل چاپگر SDK وضعیت (ESC/POS status) داشته باشد، آداپتر اختصاصی آن پشت همان رابط `PrinterAdapter` اضافه می‌شود.

### اسکنر QR

- اسکنر USB را در حالت **HID Keyboard** با پسوند **Enter** (CR) تنظیم کنید. معمولاً با بارکد تنظیمات سازنده انجام می‌شود.
- زبان صفحه‌کلید ویندوز برای حساب `kiosk` روی English (US) باشد تا نویسه‌های کد درست تایپ شوند.
- برنامه ورودی سریع اسکنر را از تایپ انسان تشخیص می‌دهد (فاصله کمتر از ۳۰۰ میلی‌ثانیه بین کلیدها).

### کارتخوان بانکی

- کیوسک با پایانه بانک (آسان پرداخت، بانک شهر و ...) از طریق یک **برنامه کمکی** کار می‌کند که SDK همان شرکت را صدا می‌زند (`adapters.payment: "helper"`). سمت کیوسک آماده و آزموده است. برنامه کمکی پس از تحویل SDK نوشته می‌شود. پروتکل، پیکربندی و آنچه باید از شرکت پرداخت گرفت: [کارتخوان و برنامه کمکی](payment-helper.md).
- تا آن زمان:
  - `mock`: فقط برای آزمون و نمایش. نوار زرد «حالت آزمایشی» همیشه دیده می‌شود.
  - `none`: کیوسک فروش را آغاز نمی‌کند.

## ۶. حالت کیوسک قفل‌شده (توصیه‌شده)

برای جلوگیری از خروج کاربر به ویندوز:

- **Windows 10/11 Pro/Enterprise**: از *Shell Launcher* (Enterprise) یا *Assigned Access* استفاده کنید. حساب `kiosk` باید فقط `AndishkadehKiosk.exe` را اجرا کند.
- **Pro بدون Assigned Access برای برنامه‌های Win32**: با Group Policy، Task Manager، تغییر کاربر و قفل را برای حساب `kiosk` غیرفعال کنید. خود برنامه با `kioskMode: true` تمام‌صفحه و بدون قاب اجرا می‌شود.
- برای دسترسی پشتیبانی، از ریموت امن (مثلاً AnyDesk با رمز) روی حساب مدیر استفاده کنید.

## ۷. عیب‌یابی و بازیابی

| وضعیت | اقدام |
| --- | --- |
| نوار «ارتباط با مرکز برقرار نیست» | شبکه و `serverUrl` را بررسی کنید. فروش خدمات با کاتالوگ ذخیره‌شده تا `offlineCatalogMaxAgeHours` ادامه دارد. اشتراک در حالت آفلاین فروخته نمی‌شود (سیاست پیش‌فرض) |
| نوار «حالت آزمایشی» | دست‌کم یک آداپتر شبیه‌سازی‌شده است. پیش از بهره‌برداری `adapters` را بررسی کنید |
| پرداخت نامشخص (UNKNOWN) | کیوسک در هر `recoverySec` از کارتخوان استعلام می‌کند. از پنل هم «استعلام» یا «تطبیق دستی مستند» ممکن است. مبلغ تا تعیین وضعیت در فروش قطعی شمرده نمی‌شود |
| قطع برق هنگام پرداخت | ژورنال پرداخت پیش از استفاده از کارتخوان ثبت شده است. پس از روشن شدن، تلاش ناتمام استعلام و نتیجه به سرور گزارش می‌شود |
| رویداد همگام‌سازی ردشده | پنل ← «همگام‌سازی»: علت را ببینید و «اعمال مجدد» یا «همگام‌سازی کیوسک» را بزنید |
| کیوسک به سرور می‌رسد اما دستگاه در پنل «قطع ارتباط» است (خطای 401 احراز هویت دستگاه) | کلید عوض شده است (کد فعال‌سازی یا «کلید جدید»). `kiosk.config.json` را پاک کنید تا صفحه راه‌اندازی باز شود و با یک کد فعال‌سازی تازه وصل شوید، یا کلید جدید را در فایل قرار دهید |
| کارت کیوسک در پنل «هنوز وصل نشده» است | هیچ دستگاهی هنوز با کد یا کلید آن وصل نشده است. روی کارت «کد فعال‌سازی» را بزنید و کد را در برنامه کیوسک وارد کنید |
| «کد فعال‌سازی نادرست است…» | کد اشتباه تایپ شده، ۳۰ دقیقه‌اش گذشته یا قبلاً استفاده شده است. در پنل «کد فعال‌سازی» تازه بگیرید |
| ورود مدیر: «ورود مدیر فقط با اتصال به مرکز ممکن است» | کیوسک آفلاین است. شبکه را بررسی کنید یا از پنل روی دستگاه دیگر استفاده کنید |
| ورود مدیر: «پنل مدیریت باز نشد» | `<serverUrl>/admin` را در مرورگر باز کنید. اگر باز نشد، `ADMIN_DIST_DIR` سرور را بررسی کنید |
| کارتخوان «خطا» با پیام «برنامه کارتخوان اجرا نشد» | `paymentHelperPath` را بررسی کنید. فروش تا رفع آن انجام نمی‌شود و مبلغی کسر نمی‌شود |
| انتقال به دستگاه جدید | پیش از تعویض، صبر کنید صف رویدادهای دستگاه در پنل صفر شود. سپس از پوشه داده نسخه پشتیبان بگیرید (ر.ک. [پشتیبان‌گیری](backup-restore.md)) |

وضعیت لحظه‌ای هر کیوسک (آخرین ارتباط، صف رویدادها، تجهیزات، نسخه برنامه) در پنل ← «کیوسک و تجهیزات» دیده می‌شود.

## ۸. به‌روزرسانی برنامه کیوسک

1. نصب‌کننده نسخه جدید را اجرا کنید. پوشه داده (`%APPDATA%\AndishkadehKiosk`) حفظ می‌شود.
2. پیش از به‌روزرسانی مطمئن شوید پرداخت نامشخص یا رویداد ارسال‌نشده‌ای نمانده است (پنل ← «کیوسک و تجهیزات»).
