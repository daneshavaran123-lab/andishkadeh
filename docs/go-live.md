# راه‌اندازی برای بهره‌برداری

ترتیب کارها برای این استقرار:
- سرور و پنل روی **لیارا**
- کیوسک **ویندوز** ۴۳ اینچ
- کارتخوان **آسان پرداخت / بانک شهر**

هر مرحله به راهنمای کامل خودش پیوند دارد.

| | مرحله | چه کسی | آماده؟ |
| --- | --- | --- | --- |
| ۱ | سرور و پنل روی لیارا | فنی | ✅ فایل‌ها و راهنما آماده |
| ۲ | تنظیم پنل: رمزها، تعرفه‌ها، تنظیمات | مدیر مرکز | ✅ |
| ۳ | نصب و راه‌اندازی کیوسک ویندوز | فنی | ✅ |
| ۴ | کارتخوان واقعی | شرکت پرداخت + فنی | ⏳ منتظر SDK آسان پرداخت |
| ۵ | آزمون روز اول و شروع | مدیر + فنی | پس از مرحله ۴ |

## ۱. سرور و پنل روی لیارا

راهنما: [استقرار روی لیارا](liara-deploy.md).

خلاصه کارها:
- ساخت دیتابیس PostgreSQL، برنامه Docker و دیسک `media` در یک شبکه خصوصی
- تعریف پنج متغیر
- استقرار با `liara deploy` یا از GitHub Actions
- بررسی `https://<برنامه>.liara.run/api/v1/health`

## ۲. تنظیم پنل

در `https://<برنامه>.liara.run/admin`:

1. **رمزها:** ورود با `admin`، سپس «تغییر رمز». رمز `operator` را از «کاربران» عوض کنید و `SEED_*_PASSWORD` را از متغیرهای لیارا حذف کنید.
2. **تعرفه‌ها:** «خدمات و تعرفه‌ها» ← فیلتر «بدون تعرفه». ۲۸ خدمت عملکرد و ۱۰ ماژول مانیتورینگ هنوز قیمت ندارند ([موارد باز](open-items.md)). قیمت تأییدشده را وارد و خدمت را فعال کنید.
3. **پلن‌های اشتراک و تخفیف‌ها** را مرور کنید.
4. **محتوای کیوسک:** متن‌ها و تصاویر صفحه خوش‌آمد.
5. **تنظیمات:**
   - مهلت نشست
   - مهلت پاسخ کارتخوان
   - سیاست‌های آفلاین (پیش‌فرض‌ها در [موارد باز](open-items.md)، بخش ۲)
6. **کیوسک:** «کیوسک و تجهیزات» ← «ثبت کیوسک جدید» (مثلاً `KIOSK-01`). کلید دستگاه فقط یک بار نمایش داده می‌شود.

## ۳. کیوسک ویندوز

راهنما: [نصب کیوسک ویندوز](windows-kiosk-install.md).

1. **آماده‌سازی ویندوز:** حساب `kiosk`، به‌روزرسانی خارج از ساعت کاری، صفحه عمودی، ساعت خودکار.
2. **نصب‌کننده:** روی همان کامپیوتر وارد پنل شوید و «کیوسک و تجهیزات» ← «برنامه کیوسک ویندوز» را بزنید.
3. **چاپگر و اسکنر:**
   - درایور چاپگر حرارتی، کاغذ ۸۰ میلی‌متر، برش خودکار
   - اسکنر QR در حالت HID با Enter
4. **صفحه «راه‌اندازی کیوسک»:**
   - آدرس `https://<برنامه>.liara.run`
   - شناسه و کلید کیوسک
   - کارتخوان: «متصل نشده» تا مرحله ۴
   - چاپگر: «چاپگر ویندوز» و انتخاب چاپگر رسید
5. **بررسی در پنل:** دستگاه «آنلاین» است و وضعیت چاپگر و اسکنر دیده می‌شود.
6. **قفل حساب `kiosk`:** با Assigned Access یا Shell Launcher.

## ۴. کارتخوان آسان پرداخت / بانک شهر

راهنما: [کارتخوان و برنامه کمکی](payment-helper.md).

1. **از بانک شهر / آسان پرداخت بخواهید:**
   - فعال‌سازی PC-POS روی پایانه
   - SDK و مستند آن: فروش، استعلام، لغو
   - نوع اتصال (شبکه، USB یا سریال)
   - پایانه یا روش آزمون
2. **برنامه کمکی** کوچکی که SDK را صدا می‌زند، طبق پروتکل همان راهنما نوشته می‌شود. سمت کیوسک از قبل آماده و آزموده است.
3. **پیکربندی:** در `kiosk.config.json` کارتخوان را `helper` کنید و مسیر برنامه کمکی را بدهید.
4. **آزمون با پایانه واقعی:** فروش کم، رد، لغو، قطع شبکه وسط تراکنش. سپس تطبیق با گزارش بانک.

تا انجام این مرحله، کیوسک با کارتخوان «متصل نشده» فروش را آغاز نمی‌کند. با «شبیه‌ساز» فقط برای نمایش و آموزش کار می‌کند و نوار «حالت آزمایشی» همیشه دیده می‌شود.

## ۵. روز اول

- [ ] `api/v1/health` نسخه درست و `"db":"ok"` نشان می‌دهد.
- [ ] رمزهای اولیه عوض و `SEED_*_PASSWORD` حذف شده‌اند.
- [ ] همه خدمات قابل فروش قیمت دارند و فعال‌اند.
- [ ] کیوسک «آنلاین» است و نوار «حالت آزمایشی» دیده نمی‌شود: کارتخوان `helper` و چاپگر `windows`.
- [ ] یک خرید واقعی با مبلغ کم: رسید چاپ شد و سفارش در پنل «پرداخت‌شده» است.
- [ ] خرید اشتراک و اسکن QR همان کارت در «ورود اعضا».
- [ ] قطع شبکه کیوسک: فروش خدمات با کاتالوگ ذخیره‌شده ادامه دارد. پس از وصل شدن، سفارش در پنل دیده می‌شود.
- [ ] پشتیبان دیتابیس گرفته شده است ([پشتیبان‌گیری](backup-restore.md)).
- [ ] تصمیم‌های کسب‌وکار ([موارد باز ← بخش ۳](open-items.md#۳-تصمیمهایی-که-تأیید-کسبوکار-لازم-دارند)) گرفته شده‌اند: احراز هویت برای صدور مجدد QR و مدت نگهداری شماره موبایل‌ها.
